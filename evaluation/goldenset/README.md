# Стартовый golden set для Movie Picker

`queries.jsonl` — UTF-8 JSON Lines: одна запись на запрос. Его удобно читать Python-кодом, сравнивать в Git и расширять без зависимостей от Excel. Есть 6 запросов и 78 оценок релевантности, по 12–16 фильмов на запрос. Все ID и названия проверяются по исходному CSV.

Поля: `query_id`, английский `query`, пояснение `query_ru`, `intent`, `filters`, `judgment_status`, `relevant_movies`. У фильма указаны `movie_id`, `title`, `relevance`. Оценка 3 — прямое соответствие, 2 — подходит, но шире намерения; 1 — слабое соответствие, 0 — явно не подходит. В начальной версии используются 2 и 3.

Это **черновая разметка для ручного уточнения**, а не полный эталон всех подходящих фильмов. Список задаёт оценённые фильмы с градациями; не требуется воспроизводить ровно такой порядок. Он не получен из выдачи проверяемого рекомендателя. Данные об актёрах из credits пока не используются.

Английский текст выбран для сопоставимого сравнения с текущим BM25 без LLM-перевода. Русский текст хранится для чтения; отдельный русскоязычный тест стоит завести с явно выбранным способом перевода, не смешивая его с этим экспериментом.

Неоценённый фильм получает 0 при вычислении метрик, хотя в действительности может подходить. Поэтому метрики показывают качество относительно этого пула оценок. Полезно собирать объединённую выдачу разных стратегий и вручную дополнять разметку, включая отрицательные примеры. Для финального сравнения нужен отдельный набор запросов, на котором не подбирались параметры.

Из `evaluation` выполните `uv run benchmark.py --mode validate`: проверяются ID, названия, фильтры и уникальность по внешнему CSV. Подготовка окружения и параметры запуска — в [инструкции](../README.md).
