# Golden set

`queries.jsonl` — UTF-8 JSON Lines, одна запись на запрос. 10 обычных запросов содержат 121 оценку фильмов, ещё 5 запросов проверяют отказ. В сервис передаётся русский `query`; исходный английский текст первых шести тем сохранён в `query_en`.

Поля: `query_id`, `kind` (`normal` или `trap`), `query`, `query_ru`, `filters`, `expected_answer`, `relevant_movies`. У фильма — `movie_id`, `title`, `relevance`. Названия сверяются с подготовленным `tmdb_5000_movies_ru.csv`.

Оценка 3 — прямое соответствие; 2 — подходит, но шире намерения; 1 — слабое; 0 — не подходит. Список задаёт градации, а не единственную допустимую перестановку. Равные оценки допускают свободный порядок. В ловушках список релевантных фильмов пуст, `expected_answer` описывает отказ.

Добавлены темы суда, Второй мировой войны, бокса и выживания. Подбор выполнен по каталогу, не по выдаче оцениваемой системы. Это черновая и неполная разметка: неоценённые подходящие фильмы могут занижать метрики. Нужна ручная верификация и независимый тестовый набор перед выводами об улучшении модели.

Ловушки: отсутствующие «Оппенгеймер», «Дюна: Часть вторая», «Барби»; диапазоны лет 2090–2099 и 1800–1850. Эти условия проверены на текущем CSV; после обновления каталога их нужно проверить снова. Узкий набор проверяет отказ приложения, но не все виды галлюцинаций LLM.

Проверка из `evaluation`: `uv run benchmark.py --mode validate`. Метрики и порядок ручной оценки — в [README](../README.md).
