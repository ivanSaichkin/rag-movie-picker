# Kinopoisk RAG Movie Recommender

RAG-система для подбора фильмов на основе отзывов и метаданных из датасета «Кинопоиск: фильмы и отзывы».

Проект использует retrieval-augmented generation: сначала находятся релевантные фильмы и отзывы по запросу пользователя, затем LLM формирует персональную подборку с обоснованием.

## Датасет

[Kinopoisk Movies & Reviews — Kaggle](https://www.kaggle.com/datasets/mikhailklemin/kinopoisks-movies-reviews)

## Стек (предполагаемый)
